🎯 API ENDPOINTS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

GET  /api/login                    → Start OAuth
GET  /api/callback?code=...        → Handle OAuth
GET  /api/me                       → User profile
GET  /api/playlists               → User playlists
GET  /api/recently-played         → Recent artists
